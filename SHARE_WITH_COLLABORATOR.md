# 🤝 How to Share This Project with Renuka Swain

## Method 1: Add as Collaborator (Recommended)

### For You (Asish):
1. Go to: https://github.com/Asishranjansahu/SMART-CAMPUS-AUTOMATION-SYSTEM
2. Click **Settings** → **Collaborators**
3. Click **Add people**
4. Enter Renuka's GitHub username or email
5. Click **Add [username] to this repository**

### For Renuka:
1. Check email for invitation
2. Click **Accept invitation**
3. Clone the repository:
   ```bash
   git clone https://github.com/Asishranjansahu/SMART-CAMPUS-AUTOMATION-SYSTEM.git
   cd SMART-CAMPUS-AUTOMATION-SYSTEM
   ```
4. Start working! Changes will appear on the same repository

**Benefits:**
- ✅ Shared repository
- ✅ Both can commit and push
- ✅ Shows on both profiles
- ✅ Unified commit history

## Method 3: Create GitHub Organization

### Steps:
1. Go to: https://github.com/settings/organizations
2. Click **New organization**
3. Name it (e.g., "smart-campus-team")
4. Add both members
5. Transfer repository to organization

### Transfer Repository:
1. Go to repository **Settings**
2. Scroll to **Danger Zone**
3. Click **Transfer ownership**
4. Enter organization name
5. Confirm transfer

**Benefits:**
- ✅ Professional team appearance
- ✅ Equal ownership
- ✅ Better for portfolios
- ✅ Shows as organization project

---

## Method 4: Duplicate to Renuka's Account

### For Renuka:
1. Create a new repository on her GitHub
2. Clone this repository locally:
   ```bash
   git clone https://github.com/Asishranjansahu/SMART-CAMPUS-AUTOMATION-SYSTEM.git
   cd SMART-CAMPUS-AUTOMATION-SYSTEM
   ```
3. Change the remote to her repository:
   ```bash
   git remote set-url origin https://github.com/RenukaSwain/SMART-CAMPUS-AUTOMATION-SYSTEM.git
   ```
4. Push to her repository:
   ```bash
   git push -u origin main
   ```

**Benefits:**
- ✅ Complete copy on her account
- ✅ Independent development
- ✅ Shows on her profile
